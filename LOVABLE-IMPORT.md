# Lovable import

1. Upload this ZIP into Lovable (Import project).
2. Run `npm i`.
3. Copy `.env.example` → `.env.local` and fill `MISTRAL_API_KEY` (never commit).
4. `npm run dev` → open /studio.

Clean pack: no node_modules, .git, .env*, tmp-*, .vercel.
